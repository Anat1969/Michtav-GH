# מכתב לעצמי לראשון בחודש

**[לאפליקציה החיה: https://michtav-gh.vercel.app](https://michtav-gh.vercel.app)**

קישור למיזוג האחרון, בלי Vercel: https://raw.githack.com/Anat1969/Michtav-GH/main/app/index.html (ב-raw.githack מופיע לפעמים דף ביניים: לוחצים "Open the page" פעם אחת).

כותבים חזון ופחד, ולכל אחד נותנים הסתברות.
המכתב נחתם, ונפתח בראשון לחודש הבא עם שאלות השוואה, ציון כיול ברייר, והשוואה למחקר על דאגות.

## מסכים
| מסך | מטרה | פעולה ראשית |
|---|---|---|
| בית `#/` | טבעת הימים עד הראשון לחודש, בעיה, פתרון ותובנה, ומפת התוכן | לכתוב מכתב |
| כתיבה `#/write` | 4 שאלות: חזון, פחד, היום (סולם קנטריל), חתימה | חתימה לשנה |
| המכתבים שלי `#/letters` | ספירה לאחור, מגמת כיול חודשית, תזכורת חודשית ליומן, גיבוי וטעינה | לשבור את החותם |
| יום הפתיחה `#/open/<id>` | קריאה, תשובות, השוואה | להשוואה |
| השיטה `#/method` | מקורות, נוסחה, מגבלות | |

## הרצה
```
npm install
npm run dev
npm run build && npm run test:e2e
```

## מבנה
- `src/logic/score.ts`: ציון ברייר, הטיית פחד וחזון, ותובנות מחושבות.
- `src/logic/questions.ts`: שאלות ההשוואה המקומיות, בלי AI.
- `src/logic/store.ts`: מכתבים במכשיר (localStorage) ובשרת (Supabase).
- `supabase/migrations/`: טבלת `michtav_letters` עם RLS שלא מחזיר תוכן לפני יום הפתיחה, ופונקציית `michtav_sealed()` למטא־נתונים.
- `supabase/functions/michtav-ai/`: Gemini החינמי קודם, Claude כגיבוי. רק בהסכמה.

## החלטות
- **פרטיות לפני AI:** בלי הסכמה מפורשת שום דבר לא יוצא מהמכשיר.
- **חותם אמיתי בשרת:** RLS מאפשר קריאה רק כש-`open_at <= now()`. טריגר מונע שינוי של המכתב אחרי החתימה.
- **תזכורת ליומן (.ics)** שחוזרת בכל ראשון לחודש, במקום מייל: אין שרת שליחה ואין תשלום.
- **מחזור חודשי:** מכתב נפתח בראשון לחודש הבא. פחות מ-7 ימים לפני כן: בראשון שאחריו.
- ציון ברייר (Brier, 1950): 0 מושלם, 0.25 הוא 50% על הכול. "חלקית" נספר כ-0.5.
